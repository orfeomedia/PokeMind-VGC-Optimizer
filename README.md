# ⚡ PokeMind VGC Optimizer 2026

PokeMind es una herramienta de análisis predictivo para el metajuego de Pokémon Showdown. 
Utiliza algoritmos de optimización para maximizar el Win-Rate basado en estadísticas de uso reales.

## ✨ Características
- **Predictive Damage Calc:** Análisis de supervivencia ante el Top 10 del meta.
- **Synergy Heatmap:** Visualización de debilidades y coberturas.
- **Auto-EV Spreader:** Optimiza tus EVs para sobrevivir a amenazas específicas (ej. Flutter Mane Specs).

## 🛠️ Instalación
`pip install -r requirements.txt`
`python app/main.py`
